📱 Client Spec

React 18 & Vite를 사용하여 고성능 웹 환경을 제공하며, 사용자 동작을 실시간으로 캡처하여 백엔드로 전달합니다.

⚙️ Backend Spec

Spring Boot 3 & JPA를 통해 비즈니스 로직을 처리하고, AI 서비스와의 보안 통신을 총괄하며 데이터를 관리합니다.

🤖 AI Engine Spec

FastAPI & LangChain 기반의 RAG 아키텍처를 사용하여 태권도 지식 베이스와 연동된 정밀 코칭을 생성합니다.

💾 Database Spec

MariaDB와 FAISS Vector DB를 병용하여 정형 데이터(분석 이력)와 비정형 데이터(벡터 지식)를 모두 수용합니다.
